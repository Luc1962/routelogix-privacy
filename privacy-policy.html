Politique de confidentialité

Dernière mise à jour : 2 janvier 2026

Introduction

G.A. Logix Logiciels inc. ("nous", "notre") exploite l'application RouteLogixAuto. Cette page vous informe de nos politiques concernant la collecte, l'utilisation et la divulgation des données personnelles lorsque vous utilisez notre application.

Données collectées

Position GPS

L'application collecte votre position GPS pour :

  • Afficher votre position sur la carte
  • Enregistrer vos trajets et observations
  • Permettre la navigation

Enregistrement audio

L'application utilise le microphone uniquement pour les commandes vocales. L'audio est :

  • Traité localement sur votre appareil
  • Utilisé uniquement pour la reconnaissance vocale
  • Non enregistré ni stocké
  • Non transmis à des serveurs externes

Stockage des données

Toutes les données (positions GPS, trajets, observations) sont stockées localement sur votre appareil. Les données peuvent être synchronisées avec les serveurs de votre entreprise selon votre configuration.

Partage des données

Nous ne vendons, n'échangeons ni ne transférons vos données personnelles à des tiers. Les données GPS peuvent être partagées avec votre employeur ou donneur d'ouvrage si vous avez configuré cette option.

Sécurité

Nous mettons en œuvre des mesures de sécurité appropriées pour protéger vos données personnelles.

Vos droits

Vous pouvez à tout moment :

  • Désactiver la localisation GPS dans les paramètres de votre appareil
  • Révoquer la permission du microphone
  • Supprimer l'application et toutes les données associées

Modifications

Nous pouvons mettre à jour cette politique de confidentialité. Les modifications seront publiées sur cette page.
